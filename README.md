# 榜一

在 1200 公里里开完 400 天。

## 怎么装

1. 用安卓 Chrome 打开 `https://<你的用户名>.github.io/bangyi/`
2. 右上角 ⋮ → 「安装应用」/「添加到主屏幕」
3. 从桌面图标打开，全屏、无地址栏、离线也能跑

## 数据

存档在浏览器 localStorage，键名 `bangyi.v03`。
换设备或清理浏览器数据前，去「设置 → 导出存档」存一份。

## 更新

改完 `bangyi-v0.6.html` → 重新生成 `pwa/` → 覆盖这四个文件。
安卓 Chrome 会因为 service worker 缓存而晚一步更新，下拉刷新两次即可。
